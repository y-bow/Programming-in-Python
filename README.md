## How to Use This Repository

### Method 1: View Online
1. Open any folder (e.g., `Lecture_2`)
2. Click on a `.py` file
3. View the code directly on GitHub

---

### Method 2: Download All Files
1. Click the **Code** button
2. Select **Download ZIP**
3. Extract the ZIP file
4. Open files using:
   - Python IDLE
   - VS Code
   - Any text editor
